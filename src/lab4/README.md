# Рекомендации фильмов и возрастные группы

Два консольных приложения на Python (только стандартная библиотека, ООП):

1. **`recommender`** — рекомендует фильм по истории просмотров всех пользователей сервиса.
   Усложнение с весами включается флагом `--weighted`.
2. **`age_groups`** — разбивает респондентов опроса по возрастным группам.

Условие задач лежит в [TASK.md](TASK.md), техническое задание в [TZ.md](TZ.md),
статус и журнал работы в [STATUS.md](STATUS.md).

## Запуск

Требуется Python 3.10+. Приложения запускаются **из корня проекта**: пути к данным
`data/movies.txt` и `data/history.txt` заданы константами относительно текущей папки
(`recommender/app.py`).

```bash
echo 2,4 | python -m recommender.app              # -> Дюна
echo 2,4 | python -m recommender.app --weighted   # -> Дюна
python -m age_groups.app 18 25 35 45 60 80 100 < respondents.txt
```

Коды возврата: `0` — успех, `1` — ошибка аргументов, ввода или файлов. Результат печатается
в stdout, ошибки и предупреждения в stderr.

### Задача 1: формат данных и пример

`data/movies.txt` — строки `id,название` (делится по первой запятой);
`data/history.txt` — в каждой строке id фильмов одного пользователя через запятую.
Пользователь вводит одной строкой id просмотренных фильмов:

```
$ echo 2,4 | python -m recommender.app
Дюна
$ echo 1,2,3,4 | python -m recommender.app
Рекомендаций нет
$ echo 2,9 | python -m recommender.app
Ошибка: фильма с id 9 нет в каталоге        (stderr, код 1)
```

## Принятые решения

### Задача 1

| Вопрос | Решение |
|---|---|
| «Хотя бы половина» | По множествам разных id: `common = len(watched & films)`, история отобрана, если `2 * common >= len(watched)` (целые числа, без `float`) |
| «Оставшийся список фильмов» | Объединение фильмов отобранных историй за вычетом `watched` |
| Область подсчёта в шаге 3 | Буквально по условию: просмотры по **всем** историям сервиса; счётчик строится один раз при загрузке |
| Дубли в истории (`2,2,2`) | Каждое вхождение — отдельный просмотр |
| Ничья | Наименьший id (условие разрешает любой, нужна детерминированность) |
| Кандидатов нет | stdout: `Рекомендаций нет`, код 0 |
| Ввод пользователя | id через запятую, пробелы допустимы, повторы схлопываются; пустая строка (или конец ввода), нецелый id, id вне каталога — stderr, код 1 |
| Ошибки в файлах | `ValueError` с именем файла и номером строки (плохой id, нет запятой, пустой элемент, повторный id, id истории вне каталога); пустые строки пропускаются; `main` ловит `ValueError` и `OSError` |
| Название с запятой | Делим по первой запятой |
| Формат id | Только ASCII-цифры: `-1`, `+1`, `1.5` отклоняются |
| Пустое название фильма | Ошибка файла |
| Язык | Python; «System.out» из условия — это stdout |

### Режим `--weighted`

| Вопрос | Решение |
|---|---|
| Вес истории | `w(h) = common(h) / len(watched)` |
| Оценка кандидата | `score(m) = Σ по всем историям w(h) * (число вхождений m в h)`; шаги 1 и 2 те же |
| Без `float` | `len(watched)` одинаков для всех историй, поэтому считается `Σ common(h) * вхождения`: порядок тот же |
| Ничья, вывод | Как в обычном режиме |
| Аргументы | Только `[]` и `["--weighted"]`, иначе сообщение об использовании и код 1 (без `argparse`) |

Проверочный сценарий (в тестах): каталог из фильмов 1–4, истории `1,2,3` / `1,4` / `1,4`,
ввод `1,2`. Обычный режим даёт фильм 4, режим весов — фильм 3.

### Задача 2

| Вопрос | Решение |
|---|---|
| Метки групп | `0-b0`, `b(i-1)+1-b(i)`, `b(last)+1+`; возраст, равный границе, входит в нижнюю группу (18 → `0-18`) |
| Допустимые границы | Хотя бы одна, целые, ≥ 0, строго возрастают; иначе использование в stderr, код 1 |
| Поиск группы | `bisect.bisect_left(bounds, age)`, O(log k) |
| Структура данных | Одна сортировка по `(-age, name)` и `itertools.groupby` по номеру группы: группы сразу от старшей к младшей, O(n log n) |
| Сравнение ФИО | Обычное сравнение строк Python (по кодам символов, `Ё` раньше `А`), без `locale` |
| Возраст выше 123 | Принимается, попадает в последнюю группу |
| Плохая строка | Предупреждение в stderr с номером строки, строка пропускается, код 0 |
| Разбор строки | По последней запятой, ФИО и возраст через `strip()` |
| `END` | После `strip()`, регистр важен; строки после `END` игнорируются; конец ввода без `END` тоже завершает список; пустые строки пропускаются |
| Респондентов нет | Пустой вывод, код 0 |

### Принятые по ходу работы

- Проект лежит в ветке `lab4` общего репозитория лабораторных, а не в отдельном репозитории.
- Отбор шага 1 оформлен списком `selected`: альтернатива «считать только по отобранным
  историям» включается заменой `self.history.views` на `sum(selected, Counter())` в одной строке
  `Recommender.recommend`.
- `bisect` импортируется модулем, чтобы мутация `bisect_left → bisect_right` была честной.

## Тесты и проверка

```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m pytest                    # тесты, 100% строк и ветвей (fail_under = 100)
.venv/bin/python tools/check.py               # lint, tests, doctest, smoke + build/facts.json
.venv/bin/python tools/check.py --mutations   # плюс 6 мутаций (tools/mutations.py)
.venv/bin/python tools/check.py --all         # всё, включая сборку и проверку PDF
```

`tools/check.py` печатает по строке `OK`/`FAIL` на этап, полные логи пишет в `build/logs/`.

## Документы (PDF)

В `docs/` лежат `report.pdf` (отчёт для преподавателя), `elevator_pitch.pdf`,
`tech_passport.pdf` (технический паспорт) и `cheatsheet.pdf` (вопросы преподавателя).
Все числа в них подставляются из `build/facts.json`, который пишет `tools/check.py`.

Чтобы указать автора, заполните `docs/meta.json`:

```json
{"student": "Иванов И. И.", "group": "ИВТ-21", "teacher": ""}
```

и пересоберите документы:

```bash
.venv/bin/python tools/check.py --all     # или: tools/check.py, затем tools/build_docs.py
```

Если поля пусты, строка «Студент: …» в отчёт не выводится.
